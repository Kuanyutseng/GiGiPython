題目一：智能超市結帳與庫存更新系統
請撰寫一個 Python 程式，模擬超市的購物結帳與庫存管理系統，整合變數、清單、字典、條件分支（if-elif-else）、for 迴圈與 continue 的應用：

1. 宣告以下初始變數與資料：
   - 庫存字典 inventory：
     ```python
     inventory = {
         "apple": {"price": 30, "stock": 5},
         "banana": {"price": 15, "stock": 0},  # 已無庫存
         "orange": {"price": 25, "stock": 3},
         "peach": {"price": 60, "stock": 2}
     }
     ```
   - 購物車清單 shopping_cart = ["apple", "watermelon", "banana", "orange", "peach"]
   - 是否為 VIP 會員布林值變數 is_vip = True
   - 最終累計消費金額變數 total_payment = 0

2. 進行購物流程判定（使用 for 迴圈遍歷 shopping_cart）：
   - 步驟 A：檢查該商品是否在庫存字典 inventory 中：
     - 若不在庫存中：印出「[商品名稱] 超市沒有販售！」，並跳過本次迴圈。
   - 步驟 B：若商品在庫存中，檢查其庫存數量 stock 是否大於 0：
     - 若庫存為 0：印出「[商品名稱] 已經售完，下次請早！」。
   - 步驟 C：若商品在庫存中且庫存大於 0：
     - 取得該商品的原價 price。
     - 進行 VIP 折扣判定：若該商品的價格大於等於 50 元，且消費者 is_vip 為 True，則該商品享有 9 折優惠，折抵後的價格需轉換為整數；否則維持原價。
     - 將該商品的購買金額（折抵後或原價）累加至 total_payment 中。
     - 將該商品在庫存字典中的 stock 庫存數量減 1。
     - 印出「成功購買 [商品名稱]！單價：[折抵後或原價] 元」。

3. 最後印出：
   - 「本次購物總金額：[總金額] 元」
   - 更新後的 inventory 庫存字典內容。

題目二：儲能電池充放電與安全保護模擬系統
請撰寫一個 Python 程式，模擬儲能系統的電池電量監控，整合 while 迴圈、break 迴圈控制、清單索引操作與條件分支判定：

1. 宣告以下初始變數與資料：
   - 當前電池電量百分比 current_power = 40
   - 安全最高電量上限百分比 max_limit = 90
   - 每小時的電量變化清單 power_inputs = [15, 20, -10, 25, 30] （正數代表充電，負數代表放電）
   - 記錄模擬經過時間的計數器變數 hour = 0

2. 使用 while 迴圈進行逐小時模擬：
   - 迴圈條件：當當前電量 current_power 小於安全上限 max_limit 且經過小時數 hour 小於電量變化清單的長度時，持續執行。
   - 迴圈內部的處理：
     - 根據目前 hour 的值，取出對應的電量變化值。
     - 更新 current_power，將變動值累加進去。
     - 累加計數器 hour 增加 1。
     - 印出當前每小時的進度，格式為：「第 [經過小時] 小時，電量變化：[變化量]%，當前電量：[更新後電量]%」。
     - 安全監控判定：
       - 若 current_power 大於等於安全上限 max_limit：
         - 印出「安全警報：電量已達或超過安全上限 [安全上限]%，自動中斷充電！」。
         - 立即結束迴圈。
       - 若 current_power 小於 0：
         - 將 current_power 重置為 0。
         - 印出「警報：電量已完全耗盡！」。

3. 迴圈結束後，印出：
   - 「模擬結束。總共執行 [經過小時] 小時，最終電量為 [最終電量]%」。
